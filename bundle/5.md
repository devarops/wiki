---
type: Pattern
title: Private Companion Repository
description: Keeps private material in a nested repository that the public repository ignores.
resource: https://github.com/devarops/wiki
tags: [git, privacy]
---

The pattern keeps private files locally inside a public repository.
The material lives in a separate Git repository called the private companion.
Name the private companion by appending a suffix to the public repository name, such as `public.private`.
Clone the private companion into a subdirectory that carries the same suffix, such as `public/private/`, on each machine.
The public repository lists that subdirectory in its `.gitignore`, so it never tracks the contents.
Git submodules provide the same benefit.
Nothing in the public repository records the private companion or its revision.
